# Excalidraw Rendering

This context describes native rendering of Excalidraw scenes and the compatibility promise made against the official renderer.

## Language

**Scene document**:
A native Excalidraw JSON document containing scene elements, application state, and embedded files. Exported images, clipboard payloads, shared links, and collaboration state are not scene documents.
_Avoid_: Excalidraw project, Excalidraw artifact

**Reference renderer**:
The renderer from the pinned official Excalidraw release whose SVG and PNG output defines expected visual behavior.
_Avoid_: Real thing, upstream latest

**Reference profile**:
The immutable identity of the reference renderer and all environment-dependent inputs that jointly determine its evidence. Each profile has a content digest.
_Avoid_: Baseline, version pin

**Compatibility revision**:
A monotonic identifier for a materially distinct static-export promise. Multiple reference profiles may share a compatibility revision only when they have no contract-relevant differences.
_Avoid_: Excalidraw version, package version

**Reference evidence**:
The versioned expected SVG and PNG outputs, with provenance, generated by the reference renderer under one reference profile.
_Avoid_: Unversioned golden files

**Perceptual parity**:
The state in which output is materially indistinguishable from the reference renderer at normal viewing, subject to explicit and tested tolerances rather than byte or pixel identity.
_Avoid_: Drop-in replacement, pixel-perfect rendering

**Format-specific parity**:
Perceptual parity judged separately against the reference renderer's SVG and PNG outputs, preserving their consumer-visible differences unless a compatibility exception applies.
_Avoid_: Cross-format normalization

**Compatibility normalization**:
Deterministic preprocessing that reproduces the rendering-affecting behavior of the reference renderer's public restore path without its random or time-dependent repairs.
_Avoid_: Full restore emulation, input cleanup

**Artifact byte stability**:
The guarantee that one renderer release produces identical artifact bytes for identical scene documents and render options across supported native and WASM targets.
_Avoid_: Reference byte identity, per-platform determinism

**Compatibility exception**:
An explicit, diagnosed, and tested departure from reference behavior required by the renderer's safety, self-containment, or determinism constraints.
_Avoid_: Silent divergence, implementation limitation

**Static export**:
A whole-scene SVG, PNG, or PDF representation without interactive editor overlays or viewport state. Frames and their clipping behavior remain part of the scene; exporting one frame separately does not.
_Avoid_: Editor snapshot, canvas rendering

**Vector-first PDF**:
A PDF static export that preserves ordinary Excalidraw geometry as PDF vectors and text as selectable text. Inherently raster source content remains raster; any additional rasterization is diagnosed and limited to the smallest unsupported nested-image or effect subtree.
_Avoid_: PDF screenshot, all-vector PDF

**Compatibility diagnostic**:
An explicit report that a scene uses behavior outside the pinned reference baseline, even when known content can still be rendered on a best-effort basis.
_Avoid_: Silent fallback, unsupported-element skip

**Best-effort rendering**:
A static export that preserves understood content and substitutes typed compatibility placeholders for rendering-affecting content it cannot reproduce, with a compatibility diagnostic for every substitution.
_Avoid_: Silent partial output, permissive rendering

**Compatibility placeholder**:
A deterministic visual replacement for an element or resource that cannot be rendered faithfully, preserving useful bounds or category information while making the loss visible.
_Avoid_: Missing content, generic error box

**Conformance corpus**:
The versioned collection of focused, real-world, adversarial, and regression scene documents used to judge parity with the reference renderer.
_Avoid_: Golden tests, fixture folder

**Semantic resource accounting**:
A compatibility-revision-specific ledger that charges canonical scene, asset, geometry, text, pixel, work, output, diagnostic, and logical-live-record events rather than implementation allocations, passes, caches, or backend operations. The same scene document, request, compatibility revision, and limits have the same ledger and resource outcome across conforming implementations and targets.
_Avoid_: Allocator accounting, backend work metering

**Asset payload occurrence**:
One supplied or recursively discovered payload-bearing value before conflict resolution, identity deduplication, or cache sharing. Every scene file payload, supplemental mapping payload, and accepted nested data payload is a separate occurrence, even when several occurrences decode to identical bytes.
_Avoid_: Cache entry, unique asset

**Semantic asset identity**:
The compatibility-revision-specific identity of one validated asset payload kind and its decoded payload bytes. Intrinsic validation, sanitization, decoding, decoded-pixel, work, and logical-memory charges are shared once per identity; occurrence admission and rendered-reference projection remain unshared.
_Avoid_: File ID, asset path
