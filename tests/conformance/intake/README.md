# Representative intake review queue

These bundles are pending review, not registered conformance cases or approved
evidence. `manifest.json` binds immutable source bytes, license/provenance and
the proposed applicability plan. `eligible_executions` is always empty.

Prepare and verify bundles with `tools/representative-intake/intake.py`. Do not
edit generated manifests to grant approval. Promotion requires reference and
viewer qualification, independently authored expectations, exact subject review,
and deliberate integration with the approved registry and target inventory.
