# excalidraw-fonts-xiaolai-extended

Xiaolai font chunks covering the extended CJK Unicode blocks (44 chunks), as shipped by Excalidraw 0.18.1.
Xiaolai is Excalifont's Chinese/Japanese/Korean fallback.

This crate is a payload of [`excalidraw-fonts`](https://crates.io/crates/excalidraw-fonts),
enabled by the `cjk` feature of
[`excalidraw-render`](https://crates.io/crates/excalidraw-render). Its API
carries no stability guarantee for other consumers.
