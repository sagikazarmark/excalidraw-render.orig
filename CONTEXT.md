# Excalidraw Rendering

This context describes native rendering of Excalidraw scenes and the compatibility promise made against the official renderer.

## Language

**Scene document**:
A native Excalidraw JSON document containing scene elements, application state, and embedded files. Exported images, clipboard payloads, shared links, and collaboration state are not scene documents.
_Avoid_: Excalidraw project, Excalidraw artifact

**Reference renderer**:
The renderer from the pinned official Excalidraw release whose SVG and PNG output defines expected visual behavior.
_Avoid_: Real thing, upstream latest

**Reference profile**:
The immutable identity of the reference renderer and all environment-dependent inputs that jointly determine evidence for one static-export target scope. Each profile has a content digest.
_Avoid_: Baseline, version pin

**Compatibility revision**:
A monotonic identifier for a static-export promise. A compatibility revision is draft until first included in a published package release and retained thereafter; target-scoped reference profiles may share a revision when their scopes are disjoint or have no contract-relevant differences where they overlap.
_Avoid_: Excalidraw version, package version

**Draft compatibility revision**:
A compatibility revision that has not appeared in a published package release and may still change before publication.
_Avoid_: Pre-1.0 revision, experimental revision

**Retained compatibility revision**:
A compatibility revision included in at least one published package release. Its targets, artifacts, diagnostics, and failure behavior remain immutable, including across later pre-1.0 releases; any contract-relevant change or new target requires the next revision.
_Avoid_: Stable revision, released package version

**Reference evidence**:
The versioned expected SVG and PNG outputs, with provenance, generated by the reference renderer under one reference profile.
_Avoid_: Unversioned golden files

**Perceptual parity**:
The state in which output is materially indistinguishable from the reference renderer at normal viewing, subject to explicit and tested tolerances rather than byte or pixel identity.
_Avoid_: Drop-in replacement, pixel-perfect rendering

**Format-specific parity**:
Perceptual parity judged separately against the reference renderer's SVG and PNG outputs, preserving their consumer-visible differences unless a compatibility exception applies.
_Avoid_: Cross-format normalization

**Compatibility normalization**:
Deterministic preprocessing that reproduces the rendering-affecting behavior of the reference renderer's public restore path without its random or time-dependent repairs.
_Avoid_: Full restore emulation, input cleanup

**Artifact byte stability**:
The guarantee that one renderer release produces identical artifact bytes for identical scene documents, export targets, and render options across supported native and WASM targets.
_Avoid_: Reference byte identity, per-platform determinism

**Canonicalized original scene document**:
The deterministic preservation-first JSON projection of an admitted scene document used for optional embedding. It retains every original value, source member and array order, and number token, but excludes source whitespace and string-escape spelling, supplemental assets, and compatibility-normalization repairs.
_Avoid_: Original bytes, normalized rendering view

**Artifact manifest**:
The versioned format-neutral JSON metadata carried by a static export to describe its export target, requested provenance, frozen pre-metadata diagnostic summary, applicable notices, and an embedded canonicalized original scene document. A frame export identifies its frame ordinal, kind, and optional source name; SVG, PNG, and PDF use different carriers for the same manifest contract.
_Avoid_: Compatibility report, format-specific metadata schema

**Compatibility exception**:
An explicit, diagnosed, and tested departure from reference behavior required by the renderer's safety, self-containment, or determinism constraints.
_Avoid_: Silent divergence, implementation limitation

**Tolerance exception**:
An approved record in a conformance case that one variant's observed difference from reference evidence, for one format, viewer, and region, has a diagnosed non-defect cause. It documents that cause, names the issue that carries the decision, and sets ceilings to the exact observed changed-pixel count and SSIM score with no margin; the case approval binds the record, and a variant that returns inside the canonical budget makes it stale.
_Avoid_: Visual exception, known-divergence suppression, test skip

**Known defect**:
A diagnosed renderer defect whose fix awaits a maintainer decision, recorded in the parity harness that observes it with its exact measurement pinned and the issue that tracks it named. It is not an approved judgment and never enters a case manifest; the pin fails the harness when the divergence moves in either direction, so the entry can neither outlive the defect nor absorb another one.
_Avoid_: Tolerance exception for a defect, suppression list, expected failure

**Static export**:
A deterministic SVG, PNG, or PDF representation of either a whole scene or one frame, without interactive editor overlays or viewport state.
_Avoid_: Editor snapshot, canvas rendering

**Scene export**:
A static export of the complete scene. Frames and their clipping behavior remain part of the exported scene.
_Avoid_: Full export, normal render

**Frame export**:
A static export targeted at one live ordinary or magic frame, cropped and populated according to the reference renderer's frame-export behavior even when persisted frame rendering is disabled. A nested frame is independently eligible for its own frame export.
_Avoid_: Frame screenshot, recursive member export

**Frame export batch**:
An ordinal-ordered collection containing at most one frame export for each selected live frame in a scene document. Nested frames remain independent targets; by default, no artifact is intentionally published unless every target has a complete artifact and viable destination, while partial publication may be explicitly requested.
_Avoid_: Multi-frame export, frame archive

**Frame ordinal**:
The one-based source-order position of a live ordinary or magic frame among all such frames in its scene document, before filtering. It provides stable discovery order and the fallback name `frame-N` when the frame has no non-empty display name.
_Avoid_: Frame index, match number

**Frame name filter**:
An optional case-sensitive regular-expression search over non-empty frame display names. Unnamed frames are selected only when no frame name filter is present.
_Avoid_: Frame selector, filename pattern

**Frame output basename**:
A portable filename component of at most 120 UTF-8 bytes, derived from a frame's non-empty display name or its frame ordinal when no usable name remains. Basenames preserve NFC-normalized readable Unicode and source case, prefix an underscore for reserved device names, use an eight-hex SHA-256 suffix when truncated, and gain source-ordered numeric suffixes when their normalized case-insensitive forms collide.
_Avoid_: Raw frame name, frame ID

**Meaningful artifact**:
A static export produced from a safe, complete, and non-misleading plan for its target. A valid empty scene or frame and a target whose local losses are fully represented by compatibility placeholders, omissions, and diagnostics remain meaningful; merely producing encodable bytes does not make an artifact meaningful.
_Avoid_: Nonempty output, any valid image

**Vector-first PDF**:
A PDF static export that preserves ordinary Excalidraw geometry as PDF vectors and text as selectable text. Inherently raster source content remains raster; any additional rasterization is diagnosed and limited to the smallest unsupported nested-image or effect subtree.
_Avoid_: PDF screenshot, all-vector PDF

**Ordinary scene text**:
The authored text of a live source text element that survives local recovery and participates in one static-export target, canonically taken from its compatibility-normalized `originalText`. Omitted text, renderer-generated labels, and text inside nested SVG images are not ordinary scene text.
_Avoid_: Rendered text, all SVG text

**Generated export text**:
Text authored by the renderer and visibly emitted into a static export, including generated embeddable labels, visible frame names, and compatibility-placeholder labels. It contributes its final emitted text rather than an `originalText` value.
_Avoid_: Ordinary scene text, nested SVG text

**SVG font demand**:
The producer-neutral, first-use-ordered declaration of resolved font families and semantic text that survives into one direct SVG target. It is created before serialization and contains neither serialized SVG nor reconstructed shaped-glyph usage.
_Avoid_: SVG text scan, glyph census

**SVG font bundle**:
The complete direct-SVG font result prepared from one SVG font demand: effective family aliases, ordered derived and unmodified font resources, mandatory notices, and exact serialization and resource-accounting data.
_Avoid_: CSS string, font cache

**Resolved font family**:
The canonical bundled font family selected after compatibility substitution for ordinary scene text or generated export text. Source family identifiers that select the same bundled family share one resolved font family without sharing their source diagnostics.
_Avoid_: Source font family, CSS font-family

**Family metadata metrics**:
The `unitsPerEm`, `ascender`, `descender`, and `lineHeight` the reference renderer declares for one source font family and uses to position its text and to fill a text element's missing line height, independent of the face that shapes the glyphs. The vertical metrics coincide with every bundled face's `hhea` table; a substituted family such as Helvetica keeps its own declared metrics while the substitute face shapes it.
_Avoid_: Face metrics, hhea metrics, substitute metrics

**Restored line height**:
The line height compatibility normalization gives a text element whose source `lineHeight` is missing or non-positive, following the pinned restore path: the normalized `height` divided by the wrapped text's EOL-normalized line count and the normalized `fontSize` when the height is positive, otherwise the source family's metadata `lineHeight`. It is never one constant across families.
_Avoid_: Default line height, 1.25 fallback, detected line height (for the family branch)

**Source line**:
One line of a text element's stored `text` as the pinned reference splits it for rendering: `\r\n`, `\r`, and `\n` each end a line, `\r\n` counting once, and the text always has at least one. Its content is what is shaped; its terminator bytes stay with it, so the per-line source text a format carries beside the glyphs (SVG `data-source-text`, PDF `ActualText`) concatenates back to the stored `text`, which is never rewritten.
_Avoid_: Newline-split line, EOL-normalized text (for the stored bytes), wrapped line

**Official font chunk**:
An immutable bundled WOFF2 resource representing one declared Unicode-range face of a resolved font family.
_Avoid_: System font, generated font

**Font family scalar set**:
The first-use-ordered set of Unicode scalar values collected for one resolved font family from participating ordinary scene text and generated export text. A selected fallback family may receive a copy of another family's complete set.
_Avoid_: Character string, rendered glyph set

**Selected font chunk**:
An official font chunk whose declared Unicode range intersects its font family scalar set. Selected chunks follow their resolved family's pinned face order and each receives the family's complete scalar set.
_Avoid_: Used glyph run, cmap match

**CJK subset trigger**:
The frozen, versioned scalar table corresponding to the reference renderer's Han, Hiragana, Katakana, Hangul, and explicit CJK punctuation, symbol, and currency predicate. An Excalifont scalar-set intersection selects Xiaolai with a copy of the complete Excalifont set.
_Avoid_: Host Unicode property, Xiaolai cmap coverage

**Font subset profile**:
The compatibility-revision-specific contract for glyph and layout closure, table treatment, metrics, variations, names, legal records, encoding, and validation of every derived font subset.
_Avoid_: Subsetter defaults, compression settings

**Qualified font chunk**:
An official font chunk whose digest, table inventory, subset behavior, safety, and deterministic encoding have passed the complete native and WASM admission gates for a font subset profile.
_Avoid_: Parseable font, supported font family

**Semantic font subset identity**:
The domain-separated SHA-256 digest of the compatibility revision, complete font subset profile, official source-chunk identity, and count-prefixed first-use-ordered Unicode scalar values. The full digest governs derivation deduplication and notices; generated OpenType full and PostScript names use its first 128 bits without making cache behavior part of output semantics.
_Avoid_: Generated-byte digest, font filename

**Derived font subset**:
A request-derived font resource containing selected scalars and their required glyph and layout closure from one qualified font chunk. An OFL-licensed derived font subset is treated as a Modified Version; required bundled fonts that are not official font chunks remain unmodified resources.
_Avoid_: Font chunk, PDF font subset

**Derived font family alias**:
The primary CSS and OpenType family name assigned to a derived font subset. Reserved Font Names use the renderer-owned aliases `ExcalidrawRender-1`, `ExcalidrawRender-3`, `ExcalidrawRender-7`, and `ExcalidrawRender-9`; non-reserved family names remain canonical resolved-family names.
_Avoid_: Source font name, Reserved Font Name

**Derived font notice**:
An artifact-manifest entry identifying one derived font subset, its official source chunk, attribution, and transformation. Applicable complete OFL and MIT license texts are carried once per artifact rather than repeated in every derived font notice.
_Avoid_: Package license bundle, font name record

**Font subset resource transcript**:
The canonical ordered semantic resource ledger for deriving and serializing selected font chunks in one direct SVG target. It is independent of allocator behavior; request-scoped cache hits and cross-target frame-batch reuse replay it independently for each target.
_Avoid_: Profiler trace, dependency allocation log

**Compatibility diagnostic**:
An explicit report that a scene uses behavior outside the pinned reference baseline, even when known content can still be rendered on a best-effort basis.
_Avoid_: Silent fallback, unsupported-element skip

**Best-effort rendering**:
A static export that preserves understood content and substitutes typed compatibility placeholders for rendering-affecting content it cannot reproduce, with a compatibility diagnostic for every substitution.
_Avoid_: Silent partial output, permissive rendering

**Compatibility placeholder**:
A deterministic visual replacement for an element or resource that cannot be rendered faithfully, preserving useful bounds or category information while making the loss visible.
_Avoid_: Missing content, generic error box

**Conformance corpus**:
The versioned collection of focused, real-world, adversarial, and regression scene documents used to judge parity with the reference renderer.
_Avoid_: Golden tests, fixture folder

**Semantic resource accounting**:
A compatibility-revision-specific ledger that charges canonical scene, asset, geometry, text, pixel, work, output, diagnostic, and logical-live-record events rather than implementation allocations, passes, caches, or backend operations. The same scene document, export target, request, compatibility revision, and limits have the same ledger and resource outcome across conforming implementations and targets; each target in a frame export batch has an independent ledger.
_Avoid_: Allocator accounting, backend work metering

**Asset payload occurrence**:
One supplied or recursively discovered payload-bearing value before conflict resolution, identity deduplication, or cache sharing. Every scene file payload, supplemental mapping payload, and accepted nested data payload is a separate occurrence, even when several occurrences decode to identical bytes.
_Avoid_: Cache entry, unique asset

**Semantic asset identity**:
The compatibility-revision-specific identity of one validated asset payload kind and its decoded payload bytes. Intrinsic validation, sanitization, decoding, decoded-pixel, work, and logical-memory charges are shared once per identity; occurrence admission and rendered-reference projection remain unshared.
_Avoid_: File ID, asset path

**Canonical WASM footprint**:
The paired raw-module and deterministic Brotli byte lengths assigned by the versioned footprint protocol to the complete WASM-safe renderer and bundled asset and license catalog. It is a regression reference, not an absolute size limit or a guarantee about a consumer application's final module.
_Avoid_: WASM download size, consumer bundle size, binary-size SLA
